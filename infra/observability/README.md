# Observability assets

Prometheus/Grafana config files for FORGE API metrics. Setup guide: **[docs/OBSERVABILITY.md](../../docs/OBSERVABILITY.md)**

| File | Use |
|------|-----|
| `prometheus-scrape.example.yml` | Self-hosted scrape example |
| `prometheus-alerts.yml` | Reference PromQL |
| `grafana-alert-rules.json` | Grafana Cloud alert rules |
| `grafana-dashboard-forge-api.json` | API dashboard import |
| `terraform/` | Metrics Endpoint scrape job (Terraform) |
