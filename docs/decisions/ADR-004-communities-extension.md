# ADR-004: Communities rooms and events

**Status:** Accepted (2026-09-02)

## Context

Communities 2.0 includes rooms/events beyond YouTube Community tab.

## Decision

**Keep** rooms and events as a labeled skill-community extension. Posts/polls/tiers remain core (YouTube Community + Memberships equivalent). Do not flag-gate rooms/events.

## Consequences

- Document as extension in product strategy
- Moderation/permissions investment continues on community stack
