# ADR-003: Skills/crafts category taxonomy

**Status:** Accepted (2026-09-02)

## Context

`Category`/`Subcategory`/`SkillTag` seeded for crafts (Woodworking → Carving). Aug 2026 roadmap listed migration to YouTube genres as open.

## Decision

**Keep** skills/crafts taxonomy. Resolve YOUTUBE_PARITY_ROADMAP §0.5 open item in favor of vertical positioning.

## Consequences

- No mass re-categorization migration
- Discovery UX emphasizes skill browse, not YouTube-style genre chips
