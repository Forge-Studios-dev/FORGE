# ADR-001: Skill-first product framing

**Status:** Accepted (2026-09-02)  
**Supersedes:** Aug 2026 “YouTube-replica core + retired skill layer” decision

## Context

Three conflicting product statements existed across docs and agent rules.

## Decision

FORGE is a **skill-first creator platform powered by YouTube-style mechanics**. YouTube patterns govern video/discovery/engagement; skill taxonomy and selective skill modules (courses, mentorship, channel points) define vertical positioning.

## Consequences

- Update `FORGE_PRODUCT_STRATEGY.md`, agent rules, `CLIENT_OVERVIEW.md`, master doc §1
- Re-enable skill module UI (P2–P3 roadmap)
- CEOS tracker tasks for retired UI marked for reopening
